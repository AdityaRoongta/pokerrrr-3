# Dunzo Club v2.1.3

15 November 2026

Betting actions use the live connection when available. If an acknowledgment is slow, the browser also sends the same command over HTTP. Both paths share a durable receipt so each accepted bet applies once.

A queued reload, sit-out, or end-after-hand request can no longer reject a valid bet just by changing the table version. The server validates the hand, betting decision and deadline. Players receive fresh table state when an expired decision is rejected.

Refresh the browser tab or reopen the installed app to load the update.
