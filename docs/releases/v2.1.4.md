# Dunzo Club v2.1.4

16 November 2026

A pending bet can use a reconnected WebSocket as soon as fresh table state arrives. The recovered socket and the original HTTP request share a command ID. The server still checks the betting decision and deadline and applies an accepted bet only once.

Unreadable saved commands are discarded automatically. The turn indicator shows when an action is sending, being checked, or waiting for a connection.

Refresh the browser tab or reopen the installed app to load the update.
