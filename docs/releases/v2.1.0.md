# Dunzo Club v2.1.0

Release date: 27 October 2026.
Production: https://dunzo-club.arun-devanathan.workers.dev/
Source: https://github.com/arundevanathan/pokerrrr-3/releases/tag/v2.1.0

## Table navigation and sound

The table menu now contains Sit Out/Sit In, Stand Up, Hand History, Game Info,
Terminate Game and Return to Lobby. Spectators do not see seat actions. Anyone
viewing the game may terminate it. Stand Up and Terminate open dedicated
confirmation dialogs with immediately visible buttons. Existing current-hand and
payout completion rules remain in force. Duplicate chat, rankings, reload, sound
and auto-deal entries have been removed. Tap your own stack's + to load chips;
use the existing felt controls for Rankings and pause/resume after showdown.
The top speaker button mutes or unmutes all game and reaction sounds together.

## Chat and mobile keyboard

The compose icon sits at the bottom-right above the action panel. Opening it
shows a dedicated typing view: slim game/turn header, complete community board
and pot, personal cards, Fold/Check-or-Call/Raise… buttons and message composer.
Branding, player seats, Rankings, raise slider and shortcuts are temporarily
hidden. The application follows the visible viewport's height and pan offsets.

Fold and Check/Call work directly while typing. Raise… dismisses the keyboard
and restores the full amount controls without submitting a bet. Sending closes
the composer/keyboard immediately; failed messages retain the draft for retry.
Expand opens game-specific history, including reactions; drafts survive this
transition. Live messages appear in tappable player speech bubbles.

## Turn and showdown presentation

A light cone points from the felt centre toward the acting player and rotates
as action moves. The target seat outline and countdown remain visible. Reduced
motion disables rotation. The action-button group has no selection-style glow.
Opponent card backs use a small peek above nameplates until reveal. Your own
wager is positioned above your seat.

Winner names, amounts and hand descriptions appear below each community board.
The exact five winning cards are highlighted; Omaha uses exactly two hole cards
and three board cards. When one player wins all pots on a board, those awards
combine. Different winners retain the necessary main/side-pot distinctions;
two-board results remain separate. Uncontested wins do not reveal private cards.

## Chip returns and persistence

Unmatched contributions return to the owner's stack once betting is resolved,
before runout voting or showdown begins. Stack, wager and contested pot update
together. The return is not a win or a separate winner-display item. Returns are
recorded in hand history and the transactional accounting audit. Tests cover
short all-ins, folds, restoration and receipt replay without double credit.

Existing production roster, sessions, balances, games and Durable Object
namespace are retained. No namespace or database migration is required. Existing
payout plans retain their original timing if a release occurs during a hand.
